## 065A-4 — BDP WebLink dry-run seguro y limpieza Cargo

- **Que:** Se implemento una prueba de sincronizacion BDP sin escrituras reales: lecturas reales de WebLink y `CreateOrder` en modo `OnlyCheck`.
- **Backend:** Nuevo servicio `BdpSyncPreflightService`, endpoint `GET /api/configuracion/bdp/sync-dry-run`, schema OpenAPI y metodo `BdpWeblinkClient::check_order()` que fuerza `OrderOperationType = 1`.
- **Frontend:** `ConfigBdp` incorpora el boton `Probar sincronizacion segura` y muestra checks por paso, estado final y preview del payload.
- **Build local:** `scripts/run-cargo.mjs` ahora ejecuta limpieza preventiva de `C:\tmp\glory-target` antes de comandos Rust que compilan y falla temprano si el disco sigue bajo.
- **Validacion:** `node --check scripts/run-cargo.mjs`, `node scripts/run-cargo.mjs test --lib bdp_sync_preflight --quiet`, `node scripts/run-cargo.mjs test --lib bdp_weblink --quiet`, `node scripts/run-cargo.mjs test --lib --quiet`, `cargo check` via wrapper, `npx tsc --noEmit` y `npm run build` pasaron.
- **Pendiente operativo:** Desplegar y ejecutar el boton en produccion contra el PC BDP real; guardar resultado `listo_para_sincronizar = true` para comunicacion al cliente antes de activar escrituras reales.
