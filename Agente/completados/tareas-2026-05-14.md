## 145A-1 — Fix DNS collision restaurante.wandori.us + refactor fix_db_auth

- **Que:** App en crash loop `28P01 password authentication failed`. Diagnóstico completo reveló que el hostname `postgres` en DATABASE_URL resolvía al `coolify-db` de Coolify (10.0.1.2) en lugar del postgres del stack (10.0.10.4), porque el container `app` está conectado simultáneamente a la red del stack Y a la red `coolify` (para Traefik). El DNS de Docker retorna el primero que encuentra, que resulta ser el alias `postgres` registrado por el contenedor `coolify-db` en la red `coolify`.
- **Fix aplicado en VPS:** Editar `/data/coolify/services/b8s0cks444o0sogo8kg8wcgw/docker-compose.yml` línea 7: `@postgres:` → `@postgres-b8s0cks444o0sogo8kg8wcgw:`. App volvió a funcionar, RestartCount=0, registro HTTP devuelve JWT.
- **Fix en coolify-manager-rs:** `fix_db_auth.rs` refactorizado para detectar automáticamente el esquema de credenciales (nuevo: `SERVICE_PASSWORD_POSTGRES`/`rust_app`/`rust_db`; legacy: `DB_PASSWORD` + parseo de `DATABASE_URL` en compose para `glory_app`/`glory`). `test_postgres_auth()` y `ALTER USER` ya no hardcodean `rust_app`/`rust_db`.
- **Archivos modificados:**
  - `coolify-manager-rs/src/commands/fix_db_auth.rs` (commit `1302517`)
  - `/data/coolify/services/b8s0cks444o0sogo8kg8wcgw/docker-compose.yml` (VPS, manual)
- **Gotchas:**
  - El error `28P01` es engañoso: puede ser mismatch de contraseña O conectar al server equivocado con credenciales correctas pero inexistentes allí
  - `pg_hba.conf trust` no resolvió el crash porque el problema era que el container era el equivocado
  - El compose on-disk en Coolify puede ser sobreescrito en el próximo redeploy — el fix permanente debe estar en el template raw del servicio (`PATCH /api/v1/services/{uuid}` o en `config/templates/`)
  - Los templates ya usan `postgres-{{STACK_UUID}}` así que nuevos stacks están protegidos
- **Sentinel:** No aplica directamente. Podría añadirse detección de `@postgres:` en DATABASE_URL para stacks Coolify.
- **GLORY:** No aplica — es lógica específica de coolify-manager-rs.
